# Zhenyu Gong Academic Website

Static academic website for GitHub Pages.

## Local preview

Open `index.html` directly, or run a local static server from this folder.

## Publish

Publish the repository as `ZhenyuGong/ZhenyuGong.github.io`. GitHub Pages will serve it at `https://zhenyugong.github.io/`.

## Updating publications

Edit the publication entries in `index.html`. Set `data-category` to `published`, `revision`, or `working` so the filters continue to work.
